EyeTrackVR for Steam Frame (Linux ARM64)
========================================

Install with FrameDrop (https://framedropvr.com/): use the "Install with
FrameDrop" button on the release page, or drop this zip onto FrameDrop.
The title shows up in the headset's Steam library as "EyeTrackVR".

Manual install with the SteamOS Devkit Client (Title Upload):
  Name:           EyeTrackVR
  Local Folder:   this folder (the one containing `eyetrackvr`)
  Start Command:  eyetrackvr
  Runtime:        Steam Linux Runtime 4.0 ARM64

On the headset, settings live in ~/.config/EyeTrackVR and logs in the
logs/ folder next to the eyetrackvr binary.
See docs/steam-frame.md in the source repository for details and limitations.
